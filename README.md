# Cam-to-CAD

Scan een fysiek onderdeel met de camera van een Android-smartphone en krijg een bewerkbaar CAD-model terug: een schone B-rep in STEP AP242 én een parametrische feature tree (CadQuery/build123d, FreeCAD).

**Status:** ontwerpfase — er is nog geen code.
